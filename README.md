# NETTOON — Animation Software Knowledge Page

## Installation
1. Copy `knowledge/animation-software.html` into your existing website's `knowledge/` directory.
2. The page references the existing shared files at the website root: `styles.css`, `knowledge.css`, `knowledge-pages.css`, `script.js`, and `theme.png`.
3. Keep the page at `knowledge/animation-software.html` so the relative links and asset paths work.
4. Replace the remote Unsplash image URLs with NETTOON-owned or appropriately licensed images when ready. For image explainers depicting people, use authentic, respectful images of Black animators and creators alongside other global representation.

## Notes
- The page uses the existing NETTOON shared header and footer classes.
- It includes its own page-specific responsive styles in the document for straightforward integration.
- Software capabilities are described at a high level. Check official vendor pages for current licensing, pricing, product status and system requirements.
- No claim is made that NETTOON is affiliated with any software vendor or animation studio.
